# 🎮 BajteBrothers – Rescue Mission

Moderna, edukativno-zabavna 2D HTML5 Canvas igra optimizirana za mobilne uređaje (iOS/Android), namijenjena djeci od 7 do 13 godina.

## 🚀 Značajke projekta
- **Glavni jezik:** Hrvatski 🇭🇷 (s opcijama za EN, DE, IT).
- **Personalizacija:** Unos imena igrača i odabir muških/ženskih heroja (Alex, Mia, Kevin, Lara, Nova).
- **Audio integracija:** Posebne glasovne poruke i audio-podrška s glasom **"Barba Željko"** izravno tijekom igranja!
- **9 jedinstvenih svjetova:** Od magične šume do high-tech tvornice, svaki nivo ima posebne prepreke (led, struja, pješčana oluja).
- **Sustav motivacije:** Bogate animacije s konfetima i personalizirane poruke na kraju svakog nivoa koje potiču dijete na nastavak misije.
- **Mobile-First kontrole:** Integriran responzivni soft-joystick i brze touch kontrole prilagođene dječjim prstima bez dosadnog zumiranja ekrana.

## 🛠️ Tehnologije
- HTML5 Canvas & CSS3 Animation
- Vanilla JavaScript (ES6+ Moduli)
- Web Audio API (za reprodukciju zvukova Barba Željka)
- LocalStorage (za spremanje napretka, zvijezda i imena)
